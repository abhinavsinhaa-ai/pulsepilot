# PulsePilot 🚀

PulsePilot is a small Python project that helps students turn tasks into a structured daily study plan.

## 🔧 What it does
- Takes tasks and priorities
- Allocates available study time
- Generates a clean daily plan

## 📂 Files
- `pulsepilot.py` — main script
- `tasks.json` — input data

## ▶️ How to run
```bash
python pulsepilot.py
